# Política de segurança

## Como reportar uma falha

Encontrou uma vulnerabilidade no site ou neste repositório? **Não abra uma issue pública.**

Use o relato privado do GitHub: aba **Security → Report a vulnerability** deste repositório.
O relato fica visível só para o mantenedor.

Inclua, se possível:

- a página ou o arquivo afetado;
- os passos para reproduzir;
- o impacto que você imagina.

## O que esperar

- Resposta inicial em até 7 dias.
- Correção priorizada conforme o impacto, com crédito a quem reportou (se quiser).
