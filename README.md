# lucasemanuel.com.br

Portfólio pessoal de Lucas Emanuel — Dev Back-end & Analista de Sistemas.

Site estático (HTML, CSS e JavaScript puro), publicado com GitHub Pages em
[lucasemanuel.com.br](https://lucasemanuel.com.br).

## Rodar localmente

```bash
python -m http.server 5500
```

Depois abra http://localhost:5500.

## Estrutura

- `index.html` — conteúdo (apresentação, skills e contatos)
- `style.css` — estilos
- `script.js` — paleta de comandos (Ctrl/⌘ + K) e botões de copiar
- `CNAME` — domínio personalizado do GitHub Pages
